Conciliação do mês

Suba a produção gerada pelo sistema e as planilhas informadas por cada dentista. Tudo fica gravado na competência: arquivos originais, decisões e versões.

1Produção do sistema

Planilha geral (ex.: "Faturamento Odonto Premier – Outubro"). A aba e as colunas são detectadas automaticamente.

2Produções informadas pelos dentistas

Suba várias de uma vez. O sistema acha a coluna de guias sozinho e sugere o dentista pelo nome do arquivo.

3Regras do cálculo

Defina o que entra na base de comissão e como tratar guias com mais de um dentista.

Situações que entram na base de comissão
Carregue a planilha do sistema.
Como o executor é definido
  1. Guia informada por um dentista → ele é o executor, mesmo que o sistema aponte outro.
  2. Guia informada por mais de um dentista → conflito, você escolhe.
  3. Sem guia válida, só com o ID do atendimento → atribui se o valor bater; senão vai para divergência.
  4. Sem planilha de dentista → usa o dentista do sistema, se estiver cadastrado.
Tolerância de divergência (R$)Diferenças até esse valor não viram divergência.

Detalhamento das guias

Divergências de valor: informado pelo dentista × sistema

Comparado por atendimento. Para cada caso, escolha a decisão e para quem vai. Manter sistema: as linhas do sistema daquele atendimento vão para o dentista escolhido. Usar valor informado: idem, mais um ajuste com a diferença, para a comissão ficar pelo valor informado.

Pendentes:

Lançamentos informados pelos dentistas que não constam no sistema

Nem a guia nem o ID do atendimento foram encontrados (produção não lançada ou guia digitada errada). Atribua a um dentista para entrar na comissão, ou marque "Não considerar".

Guias pendentes

Guias com status Pendente no sistema, com o motivo e o dentista executor. Elas ficam fora do movimento e da comissão e aparecem só aqui, para acompanhamento.

Todo procedimento que contém o texto vai direto para o dentista escolhido, antes do cruzamento com as planilhas. Ex.: "Consulta Odontológica" → CLINICA. A troca manual na linha continua valendo por cima.
